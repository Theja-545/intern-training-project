# UI/UX design principles
UX(user experience): how a user feels and interact when using a website / application.
UI (User interface): the point of interaction, communication, and control between a human and a digital device, software application, or physical machine

## 1. UX Laws
UX laws are principles based on human behaviour that help designers create user-friendly websites and applications.

| UX Law | Description | Example / Usage |
|---|---|---|
| Hick's Law | More choices increase decision time. | Limit navigation menu options. |
| Fitts's Law | Larger buttons are easier to click. | Make the Add to Cart button visible. |
| Jakob's Law | Users prefer familiar designs. | Place the shopping cart at the top-right. |
| Miller's Law | Group information into smaller sections. | Divide registration forms into sections. |
| Law of Proximity | Nearby elements appear related. | Place product names near product images. |
| Law of Similarity | Similar elements are understood as a group. | Use consistent button styles. |
| Aesthetic-Usability Effect | Attractive designs feel easier to use. | Use consistent colours and layouts. |
| Von Restorff Effect | Different elements attract attention. | Highlight the main CTA button. |
| Goal-Gradient Effect | Users are motivated by progress. | Show checkout progress indicators. |
| Peak-End Rule | Users remember important moments and endings. | Display a clear order confirmation. |

## 2. Low-Fidelity vs High-Fidelity Wireframes

A wireframe is a visual plan showing the structure and layout of a website before development.

**Low-Fidelity Wireframe**
- Basic website structure.
- Uses simple shapes and placeholders.
- Usually black, white and grey.
- Created during initial planning.
- Example: Basic boxes representing images, buttons and text.

**High-Fidelity Wireframe**
- Detailed website design.
- Uses actual colours, fonts and images.
- Includes buttons, icons and spacing.
- Created before development.
- Example: A complete e-commerce page with product images, prices and styled buttons.

**Where used:**
- Low-Fidelity: Planning layouts and discussing requirements.
- High-Fidelity: Presenting designs and testing the user experience.

## 3. Psychology of Design
Explains how visual elements influence user feelings, attention and decisions.

| Concept | Description | Example |
|---|---|---|
| Colour Psychology | Colours influence emotions. | Green for success, red for errors. |
| Visual Hierarchy | Important elements attract attention first. | Large headings and highlighted buttons. |
| Social Proof | People trust other people's experiences. | Customer reviews and ratings. |
| Emotional Design | Design creates emotional connections. | Attractive product photographs. |
| Contrast | Differences make elements stand out. | Dark text on a white background. |
| Consistency | Similar elements maintain a familiar experience. | Same button styles across pages. |
| Scarcity | Limited availability can influence decisions. | Display genuine limited-stock messages. |

**Where used:** E-commerce websites, landing pages, advertisements and mobile applications.

## 4. Cognitive Decision-Making

Explains how people process information, compare choices and make decisions.

| Concept | Description | Example / Usage |
|---|---|---|
| Attention | Focus on important information. | Highlight CTA buttons. |
| Perception | How users interpret information. | Use familiar icons. |
| Memory | Users remember previous experiences. | Familiar navigation layouts. |
| Cognitive Load | Reduce mental effort. | Keep forms simple. |
| Mental Models | Users expect familiar behaviour. | Shopping cart icons. |
| Chunking | Group information into sections. | Divide forms into steps. |
| Recognition over Recall | Recognising is easier than remembering. | Show recently viewed products. |
| Decision Fatigue | Too many decisions cause tiredness. | Simplify checkout. |
| Social Proof | Other people's opinions influence decisions. | Display customer reviews. |
| Anchoring Effect | First information influences judgement. | Show original and discounted prices. |
| Loss Aversion | People avoid potential losses. | Show genuine limited-time offers. |
| Choice Overload | Too many options create confusion. | Provide product filters. |

### Stages of Cognitive Decision-Making

1. **Attention** – User notices a product.
2. **Information Processing** – User reads product details.
3. **Evaluation** – User compares prices and features.
4. **Decision** – User selects a product.
5. **Action** – User adds the product to the cart and purchases it.

**Example:** When buying a dress online, customers notice the image, check the details, compare prices, select a dress and complete the purchase.
## tricks to engage more audience in social media
- Infinite scroll + autoplay (TikTok, Reels, YouTube Shorts): no natural stopping point, so there’s no moment to decide to quit.
- Seamless video loops (TikTok, Reels): the end of a video blends into its start, so you may not notice it ended.
- Pull-to-refresh (Instagram, X, Facebook): this works like a slot machine, since you never know what you’ll get (variable rewards).
- Double-tap to like + haptics/animation (Instagram, TikTok): a one-gesture like with instant feedback means almost no effort, so people do it more.
- Streaks (Duolingo): loss aversion makes people come back daily to avoid losing their count.
- Red notification badges (Facebook, Instagram, LinkedIn): unread counts create an open loop that’s hard to ignore.
- Social proof counters (YouTube views, TikTok likes): big numbers signal “this is worth watching”, so people join the crowd.
- Typing dots / “Seen” receipts (Messenger, WhatsApp, Instagram DMs): they create social pressure to reply and to check back.
- “Up next” autoplay countdown (YouTube, Netflix): the default choice is to continue, and stopping takes effort.
- Personalized  “For You” page (TikTok): one item at a time means no distractions and no browsing decisions, so the algorithm quickly learns you need.
