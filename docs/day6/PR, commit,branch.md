# Git Branching
    Branching allows us to create a separate workspace to work on new features or changes without affecting the     main branch.
    We can merge the changes into the main branch after completing the work.
# Git Commit
    A commit saves the changes made to the project locally.
    Each commit should have a meaningful message to identify what changes were made.
    Example: git commit -m "Add documentation folders"
# Git Pull Request (PR)
    A Pull Request is used to request a review of changes before merging them into another branch.
    Team members can review, comment, and suggest changes before approving and merging the PR.
